# Visitor
O visitor é um padrão de projeto comportamental que permite adicionar novas operações e regras à estrutura de objetos sem precisar alterar o código ou a lógica dessas classes. A lógica da operação fica encapsulada em uma classe separada (Visitor). O objeto principal apenas implementa um método que aceita a "visita", permitindo que uma rotina externa ao objeto aplique um comportamento/funcionalidade a ele.
