# DECORATOR

O decorator é um padrão de projeto estrutural que permite adicionar comportamentos, especificações, responsabilidades, etc. a um objeto de forma dinâmica, eliminando a necessidade de alterar o código original ou criar heranças desnecessárias. Isso permite não precisar criar inúmeras classes que são apenas especificações de uma classe base. A base do decorator é acoplar modificações ao objeto colocando-o dentro de objetos que já possuem esse comportamento.
